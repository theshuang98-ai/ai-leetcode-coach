## 中文描述

### 名称
AI LeetCode 私教 — 智能刷题教练

### 简短描述（132 字符以内）
AI 驱动的 LeetCode 刷题助手：自动记录解题进度、智能打分、间隔重复提醒，帮你高效备战面试。

### 详细描述

**AI LeetCode 私教** 是一款专为 LeetCode 刷题者设计的 Chrome 扩展，利用 AI 技术提供个性化的刷题指导。

#### 核心功能

- **自动进度追踪** — 每次打开 LeetCode 题目，自动记录你的解题状态（未开始/尝试中/已通过）
- **智能评分系统** — 根据解题时间、提交次数、题目难度，综合评估每一题的表现（S/A/B/C/D 五档评分）
- **间隔重复提醒** — 基于遗忘曲线，在最佳复习时机推送提醒，巩固知识点
- **个性化推荐** — 根据你的强弱项，推荐最适合的下一道题
- **数据看板** — 清晰的日历热力图、标签统计、进步趋势

#### 为什么选择 AI LeetCode 私教？

- 🎯 **有的放矢** — 告别盲目刷题，让 AI 帮你规划最优学习路径
- 🧠 **科学记忆** — 基于间隔重复理论，提升长期记忆效率
- 📊 **数据驱动** — 每道题都有评分，你可以清楚地看到自己的进步
- 🔒 **隐私优先** — 所有数据本地存储，不会上传到任何服务器

### 截图说明

1. **主界面** — 在 LeetCode 题目页面的侧边栏，显示当前题目的评分和历史记录
2. **数据看板** — 在 Web 端查看完整的统计数据、日历热力图和标签分析
3. **评分弹窗** — 解题完成后自动弹出的评分卡片，包含 S/A/B/C/D 评分和详细分析
4. **提醒通知** — 浏览器通知提醒你复习到期的题目

## English Description

### Name
AI LeetCode Coach — Smart刷题 Assistant

### Short Description (132 chars max)
AI-powered LeetCode companion: auto-track problem progress, smart scoring, spaced repetition reminders. Ace your coding interviews efficiently.

### Detailed Description

**AI LeetCode Coach** is a Chrome extension designed for LeetCode problem solvers. It leverages AI technology to provide personalized guidance throughout your刷题 journey.

#### Key Features

- **Auto Progress Tracking** — Automatically records your problem status (Not Started / Attempting / Solved) every time you open a LeetCode problem
- **Smart Scoring System** — Evaluates each problem based on solving time, submission count, and difficulty, giving an S/A/B/C/D rating
- **Spaced Repetition Reminders** — Based on the forgetting curve, pushes review reminders at optimal intervals to reinforce knowledge
- **Personalized Recommendations** — Suggests the next best problem based on your strengths and weaknesses
- **Data Dashboard** — Clear calendar heatmap, tag statistics, and progress trends on the web dashboard

#### Why AI LeetCode Coach?

- 🎯 **Targeted Practice** — Stop grinding blindly. Let AI plan your optimal learning path
- 🧠 **Scientific Memory** — Based on spaced repetition theory for long-term retention
- 📊 **Data-Driven** — Every problem gets a score. See your progress clearly
- 🔒 **Privacy First** — All data stored locally, never uploaded to any server

### Screenshot Descriptions

1. **Main Sidebar** — The sidebar on a LeetCode problem page showing the current problem's score and history
2. **Dashboard** — Web dashboard with full statistics, calendar heatmap, and tag analysis
3. **Score Card** — Auto-appearing scoring card after solving a problem, with S/A/B/C/D rating and detailed breakdown
4. **Notification** — Browser notification reminding you of problems due for review
